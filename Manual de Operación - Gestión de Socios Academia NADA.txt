Manual de Operación: Gestión de Socios (Academia NADA)Santiago, este es tu protocolo para dar de alta, actualizar y gestionar a tus clientes dentro de academia.html. El sistema está diseñado para que la "Key" sea el único punto de control.1. Estructura de un Socio (El Objeto JSON)Para agregar un socio, buscá la variable const DB_USERS en el código y pegá un nuevo bloque siguiendo este esquema exacto:"PASSWORD_DEL_CLIENTE": {
    name: "Nombre Visual",
    completedClasses: 5, // Número del 0 al 12
    nextClassDate: "Próxima Sesión: Día y Hora",
    resources: [
        { title: "Nombre del Archivo", type: "TIPO", link: "URL_DEL_PDF_O_DOC" }
    ],
    customAudit: { 
        current: [100, 40, 20, 10, 5, 2, 1, 0], // Retención real (8 puntos)
        optimized: [100, 90, 85, 80, 75, 70, 65, 60] // Tu promesa de optimización
    }
}
Nota Técnica sobre Google Drive: Para que el PDF se abra fluidamente, asegúrate de que el archivo en Drive tenga el acceso configurado como "Cualquier persona con el enlace". Copia el link y pégalo directamente en el campo link.2. Gestión de Tipos de Recursos (Labels)Para que el socio perciba el valor técnico, usá estos type en el array de resources:PDF: Documentación técnica o diagnósticos.TASK: Tareas específicas de implementación.DOC: Guiones o scripts de autoridad.KEY: Activos clave (Key Assets).ADMIN: Solo para tu usuario de control.3. Actualización de Progreso (Timeline)El sistema libera contenido automáticamente basado en completedClasses.Si ponés 2: Verá los módulos 1 y 2 desbloqueados. El módulo 3 aparecerá con el candado y la fecha de la próxima sesión.Si ponés 12: El alumno ha completado el Blueprint y tiene acceso total.4. La Gráfica de Retención (Retention Engineering)El customAudit es tu mayor herramienta de venta y retención.current: Representa la "fuga de atención" actual del cliente. Usá datos de su YouTube Analytics. Son 8 puntos que corresponden a la línea de tiempo del gráfico.optimized: Es la proyección de lo que logrará con tu intervención. Siempre debe ser una curva más alta y plana (menos caída).Protocolo de Onboarding (Paso a Paso)Crear Contraseña: Generá una clave única (ej: CLIENTE2024).Subir PDF: Subí el diagnóstico del cliente a Google Drive o Dropbox y obtené el link directo.Configurar Objeto: Copiá el bloque de código de un socio anterior, pegalo al final de DB_USERS y editá sus datos.Prueba de Humo: Entrá vos mismo a agencianada.cl/academia.html, poné la clave del cliente y verificá que los recursos y el nombre sean correctos.Tips de AutoridadNomenclatura: Nunca uses claves obvias como 1234. Usá mayúsculas y números que denoten exclusividad.Actualización en Caliente: Si estás en una sesión de consultoría y el alumno hace algo bien, decile: "Acabo de subirte un nuevo recurso a tu Vault personal". Actualizás el código en Netlify, le das a guardar, y él lo verá al refrescar. Eso es High-Ticket Service.
